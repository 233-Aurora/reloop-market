# CampusEcho 前端进度

## 当前状态

前端主流程已完成，导航与样式已做一轮收敛优化。`npm run build` 通过。

技术栈：Vue 3.5 · Vite 8 · TypeScript · Pinia 4 · Vue Router 5 · Element Plus 2 · Axios。

本地开发：`cd CampusEcho-web && npm run dev`，`/api` 代理至 `http://localhost:8080`。

## 设计系统

- `styles/tokens.css`：主色、价格色、侧栏、骨架、断点相关变量
- `styles/base.css`：`.ce-page` / `.ce-panel` / `.ce-cta` / `.ce-back-btn` / `.ce-result-bar` 等
- 断点统一 **960px**（侧栏抽屉 + 底栏同步）
- 折叠侧栏仅顶栏一处控制

## 管理端（已完成）

- `/admin`：数据概览卡片 + 快捷入口
- `/admin/users`：搜索、角色/状态筛选、详情抽屉、启停与升降权（二次确认）
- `/admin/categories`：分类树维护
- 权限：路由 `requiresAdmin` + 页面内判断 + 后端 `ADMIN` 校验

## 举报与内容治理（已完成）

- 物品详情 / 公开资料：提交举报（原因 + 10–1000 字说明）
- `/me/reports`、`/me/reports/:id`：我的举报列表与详情
- `/admin/reports`：筛选、处理（处罚动作）、驳回、恢复被屏蔽物品
- 物品 `moderationStatus=BLOCKED`：禁止编辑/上下架/改图；我的物品显示「已屏蔽」
- 管理概览展示举报总数与待处理数，并链到处理页

## 站内消息（已完成）

- `/me/messages`：消息列表、仅未读、类型分组筛选、全部已读、点击跳转关联交易/举报/物品/争议
- 顶栏铃铛未读角标；侧栏与用户菜单入口
- `stores/messages`：未读数轮询（60s），登录后启动、退出/401 清理
- 消息由后端在交易状态变化、举报处理与争议仲裁时自动写入，前端只读

## 交易争议（已完成）

- 交易详情：`ACCEPTED` 时可「发起争议」（`DisputeDialog`），与举报职责分离
- `/me/disputes`、`/me/disputes/:id`：我的争议列表与详情
- `/admin/disputes`：筛选、裁定完成/取消、驳回（恢复已接受）
- 管理概览展示争议总数与待仲裁数
- `DISPUTED` 状态：交易时间线、状态标签、操作栏提示与确认完成冻结
